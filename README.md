# BLOCKS — 俄羅斯方塊

一款以原生 HTML、CSS 與 JavaScript 製作的單機俄羅斯方塊，不需要安裝套件或啟動後端。

## 開始遊玩

**使用 Chrome：**在檔案總管找到 `index.html`，按右鍵選「開啟方式」→「Google Chrome」。也可以先開啟 Chrome，按 `Ctrl+O`，再選取 `index.html`。無需安裝、登入或網路連線。

如果電腦的瀏覽器政策不允許直接開啟本機 HTML，請以任何本機靜態檔案伺服器提供專案資料夾，再用 Chrome 開啟伺服器顯示的網址。遊戲不需要後端服務。

## 發布到網路

專案已附 GitHub Pages 工作流程：將專案推送至 GitHub 儲存庫的 `main` 分支後，GitHub Actions 會自動發布網站。請在儲存庫設定中將 Pages 的發布來源設為 **GitHub Actions**；首次部署完成後，GitHub 會顯示網站網址。部署檔位於 `.github/workflows/pages.yml`。

## 操作

| 操作 | 鍵盤 | 手機觸控 |
| --- | --- | --- |
| 左右移動 | ← / → | ← / → 按鈕 |
| 加速下降 | ↓ | ↓ 按鈕 |
| 旋轉 | ↑ | ↻ 按鈕 |
| 瞬間落下 | Space | 瞬間落下按鈕 |
| 暫停／繼續 | P | 暫停／繼續按鈕 |

包含七種標準方塊、牆踢旋轉、碰撞和堆疊、消行計分、每十行升級、下一塊預覽、最高分本機保存、暫停與重新開始。音效可用右上角按鈕切換。

## 專案檔案

- `index.html`：遊戲頁面和介面結構
- `style.css`：桌面及手機響應式樣式
- `script.js`：遊戲規則、繪圖與操作
- `README.md`：啟動方式及操作說明

遊戲程式與視覺素材均為專案內原生程式碼繪製，無需外部遊戲資產。字型若無法載入會使用系統字型替代。
